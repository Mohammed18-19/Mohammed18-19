## 🚀 Featured Projects

### 🔎 [RepoMind](https://github.com/Mohammed18-19/RepoMind)

**AI Codebase Intelligence System using RAG**

A retrieval-first system designed to help developers understand unfamiliar codebases through natural-language questions.

**What I built:**

* AST-based code-aware chunking
* `all-mpnet-base-v2` embeddings
* PostgreSQL + pgvector
* HNSW vector indexing
* Semantic + keyword retrieval
* Hybrid search with Reciprocal Rank Fusion
* Cross-encoder reranking
* Grounded Gemini generation
* Source citations with file + line references
* Persistent conversation history
* Retrieval evaluation
* Flask REST API
* Automated tests
* Docker + Docker Compose
* Structured logging and error handling

**Retrieval evaluation:** `26 / 30` queries → **86.7%**

> The goal was not to build another chatbot, but to understand how a complete RAG system is engineered from ingestion to grounded generation.

**→ [View RepoMind](https://github.com/Mohammed18-19/RepoMind)**
